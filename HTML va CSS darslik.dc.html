HTML faylni qanday ochish va ishga tushirish?

Hech qanday maxsus dastur o'rnatish shart emas! Faqat matn muharriri va brauzer (Chrome, Edge...) yetarli. 5 ta oddiy qadam:

1️⃣

Matn muharririni och

Windows'da Bloknot (Notepad), yoki bepul VS Code dasturi. Hattoki telefon notepadi ham bo'ladi.

2️⃣

Kodingni yoz

Yuqorida o'rgangan teglaringni yoz. Quyidagi to'liq namunadan boshlasang bo'ladi.

3️⃣

.html bilan saqla

Faylni index.html deb saqla. Diqqat: nom oxiri albatta .html bilan tugashi kerak (.txt emas!).

4️⃣

Faylni och = ishga tushir!

Faylga ikki marta bos — u to'g'ridan-to'g'ri brauzerda ochiladi. Tamom, sahifang ishga tushdi! 🎉

5️⃣

O'zgartir va yangila

Kodni o'zgartirsang — faylni saqla (Ctrl+S), keyin brauzerda F5 bos. Yangi natijani ko'rasan!

1-QISM

HTML — sahifaning skeleti

🏠 HTML nima va u nimaga kerak?

Tasavvur qiling, siz uy quryapsiz. Avval uyning skeleti — devorlar, xonalar, eshik va derazalar kerak. HTML (HyperText Markup Language) — aynan veb-sahifaning skeletini yasaydi: sarlavhalar qayerda turishini, matn qayerda, rasm qayerda bo'lishini belgilaydi.

🐍

Python bilan o'xshashlik: Python kompyuterga nima qilishni buyuradi. HTML esa brauzerga nimani ko'rsatishni buyuradi. Ikkisi ham — kompyuter tushunadigan til!

🤔 Sinab ko'r:

Atrofingizdagi 3 ta veb-saytni eslang. Ularning hammasi HTML bilan yasalgan. Qaysi biri sizga ko'proq yoqadi va nega?

🏷️ Teglar — HTML'ning g'ishtlari

HTML teglardan (inglizcha tag) tashkil topadi. Teg burchakli qavslar ichida yoziladi: <p>. Ko'pchilik teglar juft bo'ladi — ochiluvchi va yopiluvchi.

<p>
✅ Ochiluvchi
Matn shu yerda
</p>
🔒 Yopiluvchi

💡 Yopiluvchi tegda / (slash) belgisi bo'ladi. U brauzerga "shu teg shu yerda tugadi" deb aytadi.

🦴 Sahifaning asosiy tuzilishi

Har bir HTML sahifa bir xil skeletdan boshlanadi. Uchta asosiy qism bor: <html> (butun sahifa), <head> (yashirin sozlamalar — sarlavha nomi), va <body> (ko'rinadigan hamma narsa).

📝 KOD
<html>
  <head>
    <title>Mening sahifam</title>
  </head>
  <body>
    <h1>Salom dunyo!</h1>
  </body>
</html>
👀 NATIJA
🔖 Mening sahifam

Salom dunyo!

Diqqat: title ichidagi yozuv brauzer chetidagi yorliqda (tab) ko'rinadi, sahifa ichida emas!

📢 Sarlavhalar: <h1> dan <h6> gacha

Sarlavhalar matnni kattalik darajasiga ajratadi. <h1> — eng katta va eng muhim (kitobning nomi kabi), <h6> — eng kichik.

📝 KOD
<h1>Eng katta</h1>
<h2>Kattaroq</h2>
<h3>O'rta</h3>
<h4>Kichikroq</h4>

Kattaroq

O'rta

Kichikroq

🤔 Sinab ko'r: nega faqat bitta <h1> ishlatish kerak? (javobni ko'rish)

Chunki <h1> — sahifaning asosiy nomi. Kitobda ham faqat bitta sarlavha bo'lgani kabi, bir sahifada bitta <h1> bo'lgani yaxshi. Qolganlari uchun <h2>, <h3> ishlating.

📄 Paragraf — <p>

Oddiy matn yozish uchun <p> (paragraph = paragraf) tegidan foydalanamiz. Har bir <p> yangi qatordan boshlanadi.

📝 KOD
<p>Men HTML o'rganyapman.</p>
<p>Bu juda qiziqarli! 🎉</p>
👀 NATIJA

Men HTML o'rganyapman.

Bu juda qiziqarli! 🎉

🖼️ Rasm <img> va havola <a>

<img> — sahifaga rasm qo'yadi. src ichida rasmning manzili yoziladi. <a> — bosiladigan havola (link) yasaydi, href ichida qayerga olib borishi yoziladi.

💡 src va href — bular atribut (qo'shimcha ma'lumot) deyiladi. Ular tegga "qanaqa" degan savolga javob beradi.

📝 KOD
<img src="quyosh.png">

<a href="https://google.com">
  Google'ga o'tish
</a>
👀 NATIJA
🔗 Google'ga o'tish

📋 Ro'yxatlar: <ul>, <ol>, <li>

🐍

Python bilan o'xshashlik: Python'da mevalar = ["olma", "banan"] ro'yxat yasaganingiz kabi, HTML'da ham <ul> ro'yxat yasaydi! Har bir element — <li> (list item).

<ul> — tartibsiz ro'yxat (• nuqtalar bilan). <ol> — tartibli ro'yxat (1, 2, 3 raqamlar bilan).

📝 KOD
<ul>
  <li>Olma 🍎</li>
  <li>Banan 🍌</li>
</ul>

<ol>
  <li>Uyg'onish</li>
  <li>Nonushta</li>
</ol>
👀 NATIJA
  • Olma 🍎
  • Banan 🍌
  1. Uyg'onish
  2. Nonushta

🔘 Tugma <button> va kiritish maydoni <input>

🐍

Python bilan o'xshashlik: Python'da input() foydalanuvchidan ma'lumot so'raydi. HTML'da ham <input> aynan shu ish uchun — yozish uchun maydon yasaydi!

📝 KOD
<input placeholder="Ismingiz">

<button>Yuborish</button>

2-QISM

HTML'ni chuqurroq o'rganamiz

📦 <div> — HTML'ning eng muhim qutisi

<div> — bu quti (inglizcha division = bo'lim). U o'zi hech narsa ko'rsatmaydi, lekin bir nechta elementni bitta guruhga yig'adi. Xuddi o'yinchoqlarni qutiga solib qo'ygandek! 📦

Nega kerak? Chunki guruhlangan elementlarni keyin birga harakatlantirish, bo'yash yoki joylash oson bo'ladi.

📝 KOD
<div>
  <h3>Mushuk 🐱</h3>
  <p>Yumshoq va sevimli</p>
</div>

<div>
  <h3>It 🐶</h3>
  <p>Sodiq do'st</p>
</div>
👀 NATIJA — har bir div alohida quti

Mushuk 🐱

Yumshoq va sevimli

It 🐶

Sodiq do'st

🐍

Python bilan o'xshashlik: Python'da bog'liq ma'lumotlarni dict ichiga yig'asiz. <div> ham — bog'liq elementlarni bitta joyga yig'adi!

🤔 Sinab ko'r:

O'zing haqingda bitta <div> yasa: ichiga <h3> bilan isming, <p> bilan sevimli rangingni yoz. O'yin maydonida bajar!

✏️ Matnni bezash: <span>, <b>, <i>

Ba'zan jumlaning faqat bitta so'zini ajratib ko'rsatmoqchi bo'lasan. Buning uchun maxsus teglar bor:

  • <b> yoki <strong> — so'zni qalin (qora) qiladi
  • <i> yoki <em> — so'zni qiyshiq (kursiv) qiladi
  • <span> — kichik matn bo'lagini ajratadi (div kabi, lekin qator ichida)
📝 KOD
<p>
  Men <b>HTML</b>ni
  <i>juda</i> yaxshi
  <span>ko'raman</span>!
</p>
👀 NATIJA

Men HTMLni juda yaxshi ko'raman!

📌 div vs span: <div> — katta quti (yangi qatordan boshlanadi). <span> — kichik bo'lak (jumla ichida, qatorni buzmaydi).

🏗️ Sahifaning bo'limlari

Haqiqiy veb-sahifa bo'limlardan iborat: yuqorida shapka, o'rtada asosiy qism, pastda futer. Ular uchun maxsus, "ma'noli" teglar bor (oddiy div'dan ko'ra tushunarliroq):

📝 KOD
<header>Logotip va menyu</header>

<nav>Bo'limlar ro'yxati</nav>

<main>Asosiy matn</main>

<footer>Pastki ma'lumot</footer>
👀 NATIJA — sahifa xaritasi
<header> — Shapka 🎩
<nav> — Menyu 🧭
<main> — Asosiy qism 📄
<footer> — Futer 🦶
💡 Ular aslida <div> kabi ishlaydi, lekin nomi ma'noli — kodni o'qigan odam (va Google!) sahifa tuzilishini darhol tushunadi.

💬 Izohlar va foydali kichik teglar

👀 NATIJA

Birinchi qator
Ikkinchi qator

Chiziqdan keyingi matn

  • <!-- ... --> — izoh. Faqat dasturchi ko'radi, brauzer ko'rsatmaydi. Kodga eslatma yozish uchun.
  • <br> — yangi qatorga o'tkazadi (matn ichida)
  • <hr> — gorizontal ajratuvchi chiziq chizadi
🐍

Python bilan o'xshashlik: Python'da # izoh yozasiz, HTML'da esa <!-- izoh -->. Ikkalasi ham eslatma — kod ishlamaydi!

🎁 HAMMASI BIRGA

📄 To'liq namuna — bitta faylda hammasi!

Bu kodda biz o'rgangan hamma narsa bor: bo'limlar (header, nav, main, footer), qutilar (<div>), matn bezash (<span> <b> <i>), izoh, <br> va <hr>. Nusxalab, index.html ga saqla va brauzerda och! 🚀

✅ TO'LIQ KOD — index.html
index.html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Mening uy hayvonim</title>

    <!-- CSS — sahifani bezaymiz -->
    <style>
      body   { font-family: sans-serif; background: #FFF6EC; margin: 0; }
      header { background: #FF6B4A; color: white; padding: 20px; text-align: center; }
      nav    { background: #FFEDE0; padding: 12px 20px; }
      nav a  { color: #2A6FDB; font-weight: bold; margin-right: 16px; }
      main   { padding: 20px; }
      .karta { background: #FFF0EA; border-radius: 14px; padding: 18px; }
      footer { background: #2D2B3A; color: white; padding: 14px; text-align: center; }
    </style>
  </head>

  <body>

    <!-- ===== Yuqori qism ===== -->
    <header>
      <h1>🐱 Mushugim Barsik</h1>
    </header>

    <!-- ===== Menyu ===== -->
    <nav>
      <a href="#">Bosh sahifa</a>
      <a href="#">Suratlar</a>
      <a href="#">Aloqa</a>
    </nav>

    <!-- ===== Asosiy kontent ===== -->
    <main>

      <!-- div = quti, ichiga boshqa narsa joylaymiz -->
      <div class="karta">
        <h2>Barsik haqida</h2>

        <!-- span/b/i bilan matnni bezaymiz -->
        <p>
          Uning ismi <b>Barsik</b>,
          yoshi <i>3 yosh</i> va u
          <span style="color:orange">juda quvnoq</span>!
        </p>

        <p>Birinchi qator<br>
        Ikkinchi qator</p>

        <hr>

        <h3>Yaxshi ko'rgan narsalari:</h3>
        <ul>
          <li>Baliq 🐟</li>
          <li>Uxlash 😴</li>
          <li>O'ynash 🧶</li>
        </ul>
      </div>

    </main>

    <!-- ===== Pastki qism ===== -->
    <footer>
      <p>© 2026 Barsikning sahifasi</p>
    </footer>

  </body>
</html>

🚀 Qisqa yo'llar — tez yozish sirlari!

VS Code dasturida sehrli qisqa yo'llar bor (ularga Emmet deyiladi). Qisqa yozasan, Tab tugmasini bosasan — to'liq kodga aylanadi! 🪄

! + Tab
➜

Butun HTML skeletini (<html>, <head>, <body>) bir zumda yozadi!

ul>li*3 + Tab
➜

3 ta <li> bo'lgan ro'yxatni avtomatik yasaydi! (*3 = 3 marta)

h1 + Tab
➜

<h1></h1> ni to'liq, yopiluvchi tegi bilan yasaydi

🐍

Python bilan o'xshashlik: Python'da for i in range(3) bilan ishni 3 marta takrorlaysiz. Emmet'dagi *3 ham xuddi shunday — 3 marta nusxa oladi!

⌨️ Eng foydali tugma birikmalari: saqlash — Ctrl+S, ortga qaytarish — Ctrl+Z, nusxa olish — Ctrl+C, qo'yish — Ctrl+V.
