🧠 Kompyuter qanday "qaror" qabul qiladi?

Agar... — if / else

Biz har kuni qaror qilamiz: "Agar yomg'ir yog'sa, soyabon olaman." Kompyuter ham xuddi shunday o'ylaydi — if va else bilan. Kel, kompyuterga fikrlashni o'rgatamiz! 🎉

🤔 Agar (if) 🔀 Aks holda (else) ⚖️ Belgilar 🏅 else if 🔗 VA / YOKI 📒 Uy vazifasi
🧭

Bu darslik faqat "qaror qilish" haqida! if — Agar degani. Kompyuterga aytamiz: "AGAR bu to'g'ri bo'lsa — buni qil, AKS HOLDA — buni qil." Har tugmani bos va slayderni sur — o'zing sinab ko'r! 👆

🤔
1-BO'LIM

Agar... (if) — shart nima?

Hayotda biz shunday o'ylaymiz: "AGAR yomg'ir yog'sa → soyabon olaman." Bu yerda "yomg'ir yog'sa" — shart (to'g'ri yoki noto'g'ri bo'lishi mumkin). JavaScript'da buni if bilan yozamiz. Shart to'g'ri (true) bo'lsa — { } ichidagi kod ishlaydi. Noto'g'ri bo'lsa — hech narsa bo'lmaydi! 🪄

if (shart) {
  // AGAR shart TO'G'RI bo'lsa,
  // faqat shu yer ishlaydi 👇
}
▸ MISOL — yomg'ir bormi?
function tekshir() {
  let yomgir = true;   // yomg'ir yog'yapti

  if (yomgir) {
    javob = "☂️ Soyabon ol!";
  }
  // agar yomgir = false bo'lsa,
  // bu yer umuman ishlamaydi
}

2-BO'LIM

Aks holda (else) — ikkinchi yo'l

Ko'pincha bizga ikkita yo'l kerak: "Agar shart to'g'ri bo'lsa — buni, aks holda — buni." else — "aks holda" degani. U if yolg'iz qolmasin, ikkinchi yo'lni ko'rsatadi. Yoshni surib ko'r — kompyuter qaror qiladi! 👇

if (shart) {
  // shart TO'G'RI bo'lsa — bu
} else {
  // AKS HOLDA — bu ishlaydi
}
▸ MISOL — maktabga tayyormisan?
function tekshir() {
  let yosh = 7;

  if (yosh >= 7) {
    javob = "🎒 Maktabga!";
  } else {
    javob = "🧸 Bog'chaga!";
  }
  document.getElementById("j").textContent = javob;
}

4-BO'LIM

else if — ko'p yo'l

Ba'zan ikkita emas, ko'p yo'l kerak: 5, 4, 3 yoki 2 baho. Buning uchun o'rtaga else if ("aks holda agar") qo'shamiz. Kompyuter yuqoridan pastga tekshiradi va birinchi to'g'ri yo'lda to'xtaydi. Ballni surib bahoni ko'r! 🏅

function baho(ball) {
  if (ball >= 90) {
    return "5 — A'lo 🌟";
  } else if (ball >= 70) {
    return "4 — Yaxshi 😊";
  } else if (ball >= 50) {
    return "3 — O'rta 🙂";
  } else {
    return "Harakat qil 💪";
  }
}

5-BO'LIM

VA (&&) va YOKI (||)

Ba'zan ikkita shart birga kerak: "AGAR havo issiq VA dam olish kuni bo'lsa → plyajga!". && = VA (ikkalasi ham to'g'ri bo'lishi shart). || = YOKI (bittasi yetarli). Ikkala tugmani bosib sinab ko'r! 🏖️

function reja() {
  // ikkala shart ham TO'G'RI bo'lishi kerak
  if (issiq && damOlish) {
    javob = "🏖️ Plyajga boramiz!";
  } else {
    javob = "🏠 Uyda qolamiz.";
  }
}

MASHQ QILAMIZ

Uy vazifasi 🏠

Har birini yangi index.html faylga yozib, brauzerda och. if va else ni o'zing yoz! 💪

1
🎂 Yosh tekshiruvchi

Bir yosh o'zgaruvchisi yoz. Agar 18 dan katta yoki teng bo'lsa "Kattasan 🧑", aks holda "Hali kichiksan 🧒" chiqarsin.

2
🔐 Sirli parol

Tugma bosilganda parolni tekshir. Agar parol === 1234 bo'lsa "🔓 Ochildi!", aks holda "🔒 Xato parol!" chiqarsin.

3
🚦 Svetofor (else if)

Bir rang o'zgaruvchisi yoz. Agar "qizil" → "To'xta! 🛑", aks holda agar "sariq" → "Tayyorlan! ⏳", aks holda "Yur! ✅".

4
⭐ Juft yoki toq (qiyin!)

Bir son yoz. Agar son % 2 === 0 bo'lsa "Juft son 🟢", aks holda "Toq son 🔵" chiqarsin.
💡 % — bo'lishdan qolgan qoldiqni beradi.
