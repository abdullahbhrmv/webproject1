Tasodif — Math.random

Kompyuter tanga tashlaydi, zar otadi, rang aralashtiradi va sen bilan o'yin o'ynaydi — hammasi bitta sehrli buyruq bilan: Math.random(). Kel, birga o'rganamiz! 🎉

🎯 Asoslari 🎲 Zar 🍎 Massivdan 🌈 Rang 🍀 + Shart 🎮 O'yin 📒 Uy vazifasi
🎰

Bu darslik faqat tasodif haqida! Biz Math.random() ni oddiydan murakkabga qadam-baqadam o'rganamiz: sehrli sondan boshlab, to butun boshli o'yingacha. Har tugma va slayderni o'zing bos! 👆

1-BO'LIM

Math.random() nima qiladi?

Math.random() — kompyuterning sehrli tugmasi. Har chaqirilganda u 0 dan 1 gacha tasodifiy kasr son beradi: masalan 0.0374, keyin 0.8121, keyin 0.5567… Hech qachon oldindan bilib bo'lmaydi! 🪄

▸ MISOL 2 — foizga aylantiramiz (× 100)

Kasr sonni × 100 qilsak — 0 dan 100 gacha "baxt foizi" chiqadi. Baxt o'lchagichni sina! 👇

function baxt() {
  // 0-1 kasrni 0-100 ga cho'zamiz
  let foiz = Math.random() * 100;
  // pastga yaxlitlab butun son qilamiz
  foiz = Math.floor(foiz);
  document.getElementById("f").textContent = foiz + "%";
}

▸ MISOL 2 — butunlay yangi HEX rang

HEX rang — # va 6 ta belgi (0-9, A-F). Har belgini tasodifan tanlab ulasak — 16 million rangdan biri chiqadi! 🤯

function yangiRang() {
  let belgilar = "0123456789ABCDEF";
  let rang = "#";
  // 6 marta tasodifiy belgi qo'shamiz
  for (let i = 0; i < 6; i++) {
    let n = Math.floor(Math.random() * 16);
    rang = rang + belgilar[n];
  }
  document.getElementById("q").style.background = rang;
}

<!DOCTYPE html>
<html>
<body>
  <h1>Sonni top! (1 dan 20 gacha)</h1>
  <input id="taxmin" type="number">

  <script>
    // 1) TASODIF: kompyuter 1-20 orasidan son yashiradi
    let maxfiy = Math.floor(Math.random() * 20) + 1;
    let urinish = 0;

    function tekshir() {
      // 2) foydalanuvchi yozgan sonni olamiz
      let taxmin = Number(document.getElementById("taxmin").value);
      let xabar = document.getElementById("xabar");
      urinish = urinish + 1;   // O'ZGARUVCHI: urinishni sanaymiz

      // 3) SHART: uch holatni tekshiramiz
      if (taxmin === maxfiy) {
        xabar.textContent = "TOPDING! 🎉 Urinish: " + urinish;
      } else if (taxmin < maxfiy) {
        xabar.textContent = "Kattaroq son tanla! ⬆️";
      } else {
        xabar.textContent = "Kichikroq son tanla! ⬇️";
      }
    }
  </script>
</body>
</html>

VAQTI KELDI — 6 VAZIFA

Uy vazifasi

Vazifalar osondan qiyinga qadar tartiblangan. Har biri uchun yangi index.html yasa, Math.random() ishlat va brauzerda sina. Tiqilib qolsang — 💡 Maslahatni och! ⚡

1

🪙 Tanga tashlovchi

⭐

Tugma yasa. Bosilganda alert bilan "🦅 Burgut" yoki "🔢 Raqam" chiqsin (50/50).

🎯 Maqsad: Math.random() < 0.5 + if/else. Natija: har bosishda ikki javobdan biri.
💡 Maslahat — Vazifa 1

let s = Math.random(); qilib, keyin if (s < 0.5) alert("🦅 Burgut"); else alert("🔢 Raqam"); yoz. Tamom!

2

🎲 Baxt zari

⭐

Tugma bosilganda 1 dan 6 gacha tasodifiy son chiqsin va sahifada katta qilib ko'rsatilsin (alert emas, textContent).

🎯 Maqsad: Math.floor(Math.random()*6)+1. Natija: ekranda 1-6 orasida son.
💡 Maslahat — Vazifa 2

<h1 id="son">?</h1> qo'y, keyin funksiyada document.getElementById("son").textContent = Math.floor(Math.random()*6)+1;. Xohlasang zar yuzlari massivini ham qo'shib qo'y!

3

🍕 Bugun nima yeymiz?

⭐⭐

5-6 ta taom nomini massivga sol. Tugma bosilganda JS tasodifan bittasini tanlab ekranga chiqarsin: "Bugun: 🍕 Pitsa!".

🎯 Maqsad: massiv + royxat[tasodifiy_orin]. Natija: har bosishda boshqa taom.
💡 Maslahat — Vazifa 3

let taomlar = ["🍕 Pitsa","🍔 Burger","🍜 Lag'mon","🥟 Chuchvara"]; yasang, so'ng let n = Math.floor(Math.random()*taomlar.length); — taomlar[n] ni ko'rsat.

4

🌈 Tasodifiy fon rangi

⭐⭐

Tugma bosilganda butun sahifa foni (document.body) tasodifiy rangga bo'yalsin. Tayyor ranglar ro'yxatidan tanla.

🎯 Maqsad: massiv + document.body.style.background. Natija: sahifa har bosishda yangi rang.
💡 Maslahat — Vazifa 4

Meva misolidagi kabi, lekin .textContent o'rniga document.body.style.background = ranglar[n]; yoz. Ranglar: ["#FFD6E8","#D6F5E3","#D6E4FF","#FFF3C4"] kabi och ranglar chiroyli chiqadi.

5

🔮 Sehrli shar

⭐⭐⭐

Savolingga javob beruvchi sehrli shar yasa. 5-6 ta javobni massivga sol ("Ha 😄", "Yo'q 🙅", "Ehtimol 🤔"…). Tugma bosilganda tasodifan bittasini ko'rsatsin.

🎯 Maqsad: massiv + Math.random + textContent birga. Natija: har savolga tasodifiy javob.
💡 Maslahat — Vazifa 5

Bu 3-bo'limdagi "maqtovchi" bilan bir xil! Faqat gaplarni javoblarga almashtir: let javoblar = ["Ha 😄","Yo'q 🙅","Ehtimol 🤔","Albatta! 🌟","Hozir emas ⏰"];

6

🎯 O'zingning "Sonni top" o'ying

⭐⭐⭐

Darslikdagi "Sonni top" o'yinini o'zing noldan yoz. Kompyuter 1-10 orasidan son yashirsin, sen taxmin qil, JS "kattaroq/kichikroq/topding" desin. Urinishlarni ham sana!

🎯 Maqsad: random + o'zgaruvchi + if/else if/else — hammasi birga! Natija: ishlaydigan o'yin.
💡 Maslahat — Vazifa 6

Yuqoridagi 📄 "Sonni top" to'liq kodini och, nusxalab ol va * 20 ni * 10 ga o'zgartir. Keyin o'zingga moslab bezab chiq. Bu — eng katta yutuq! 🏆
