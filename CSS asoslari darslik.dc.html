CSS asoslari

HTML sahifani yasading — endi uni bezaymiz! Rang, shrift, joylashuv... CSS shu yerda boshlanadi. Bu — "CSS sehrlari"dan oldingi dars: poydevorni qo'yamiz. 🧱

🧭

HTML = nima borligi (skelet). CSS = qanday ko'rinishi (kiyim). Bu darsda CSS'ning poydevorini o'rganamiz: ranglarni qanday qo'yish, shriftni o'zgartirish va eng muhimi — box model. Har bo'limda slayderlarni surib sina! 🎚️

🎨

CSS nima va qanday ulanadi?

CSS (Cascading Style Sheets) — sahifani bezash tili. HTML "bu sarlavha" desa, CSS "u ko'k va katta bo'lsin" deydi. 🎨

CSS qoidasi doim bir xil ko'rinadi: kimni bezashni (selektor), keyin qanday bezashni (xususiyat: qiymat) yozasan.

h1 {
  color: blue;
}
↑ selektor (kimni?) ↑ xususiyat ↑ qiymat

CSS'ni HTML'ga ulashning 3 yo'li bor:

1️⃣ style="" atributi

Bitta teg ichida, tezkor. Kichik o'zgarish uchun.

<p style="color:red">
  Salom
</p>
2️⃣ <style> tegi

<head> ichida. Bir sahifa uchun eng qulay.

<style>
  p { color: red; }
</style>
3️⃣ Alohida .css fayl

Katta saytlar uchun. style.css faylga yozib, ulaysan.

<link rel="stylesheet"
  href="style.css">
💡

Biz darsda ko'pincha 2-yo'l (<style> tegi)ni ishlatamiz — eng qulay va tushunarli!

Rang va fon

color — matn rangi. background — fon rangi. Rangni nom (red), yoki HEX kod (#E84CA0) bilan beramiz. Tanlab ko'r! 👇

CSS'NING YURAGI

Box model — quti modeli

Bu — CSS'dagi eng muhim tushuncha! Har bir element — quti. Quti 4 qatlamdan iborat: ichkaridan tashqariga — content → padding → border → margin.

🎁 Tasavvur qil: content — sovg'a, padding — qutidagi yumshoq to'ldirma, border — quti devori, margin — qutilar orasidagi bo'sh joy.

🟧 margin (tashqi bo'shliq): {{ bmMargin }}px
⬛ border (devor): {{ bmBorder }}px
🟩 padding (ichki bo'shliq): {{ bmPadding }}px
.quti {
  margin: {{ bmMargin }}px;
  border: {{ bmBorder }}px solid;
  padding: {{ bmPadding }}px;
}
margin
padding
content
(matn / rasm)
🟧 margin ⬛ border 🟩 padding 🟦 content
💡

padding — devorning ichidagi bo'shliq (fon rangi bilan to'ladi). margin — devorning tashqarisidagi bo'shliq (boshqa qutilarni itaradi). Mana shu farqni ko'p odam adashtiradi!

📄 To'liq kod — nusxalab brauzerda och
index.html
<!DOCTYPE html>
<html>
<head>
  <style>
    .quti {
      width: 200px;
      background: #C9EBD4;
      margin: 16px;               /* tashqi bo'shliq */
      border: 6px solid #B45309;  /* devor */
      padding: 18px;              /* ichki bo'shliq */
    }
  </style>
</head>
<body>
  <div class="quti">Men box modelman! 📦</div>
</body>
</html>

Rasm va markazlash

Rasm qo'yish uchun <img> tegidan foydalanamiz. U yopilmaydigan teg — src (manzil) va width (eni) beriladi:

<img src="mushuk.jpg" width="200">

Rasm odatda chap tomonda turadi. Uni markazga olishning 3 yo'li bor — tugmalarni bosib solishtir! 👇

👀 SAHIFA (.sahifa)
🖼️
rasm.jpg
{{ centerCode }}

{{ centerTip }}

💡

Flex yo'li eng kuchli: u rasmni gorizontal (justify-content) ham, vertikal (align-items) ham markazlaydi. Bir vaqtning o'zida markazga qo'yishning eng ishonchli usuli!

📄 To'liq kod — flex bilan to'liq markaz (nusxalab och)
index.html
<!DOCTYPE html>
<html>
<head>
  <style>
    .sahifa {
      display: flex;               /* flex qutiga aylantiradi */
      justify-content: center;     /* gorizontal markaz */
      align-items: center;         /* vertikal markaz */
      height: 300px;
      background: #ECFAFA;
    }
    .rasm {
      width: 200px;
      border-radius: 16px;         /* burchaklarni yumaloqlaydi */
    }
  </style>
</head>
<body>
  <div class="sahifa">
    <img class="rasm" src="mushuk.jpg">
  </div>
</body>
</html>
🔍 Kod qanday ishlaydi?
display: flexOnani (.sahifa) flex qutiga aylantiradi — ichidagilar boshqariladi.
justify-content: centerRasmni gorizontal (chap-o'ng) markazga qo'yadi.
align-items: centerRasmni vertikal (yuqori-past) markazga qo'yadi.
border-radius: 16pxRasm burchaklarini yumaloqlaydi (bonus!).

VAQTI KELDI

Uy vazifasi

Yangi index.html yasa, <head> ichiga <style> qo'shib CSS yoz, brauzerda och! 🎨

1

🌈 Rangli sarlavha

Bitta <h1> yasa va <style> ichida unga color va background ber. Sevimli ranglaringni tanla!

🎯 Maqsad: selektor + color + background
2

🎯 class bilan bo'yash

Ikkita <p> yoz. Bittasiga class="muhim" ber va faqat .muhim selektori bilan uni qizil qil. Ikkinchisi o'zgarmasligi kerak!

🎯 Maqsad: .class selektorini ishlatish
3

📦 Chiroyli quti

Bitta <div> yasa va unga padding, border va background ber. Box model'ni his qil — paddingni o'zgartirib ko'r!

🎯 Maqsad: padding + border + background
⭐

🎁 Qo'shimcha (qiyinroq!) — Tashrif kartasi

Bitta quti (div) ichida ismingni (h2) va kasbingni (p) yoz. Qutiga background, padding, border-radius va width ber. Matnlarga rang va text-align: center qo'sh!

🎯 Maqsad: bugun o'rganganlarning hammasi birga!
💡 Yordam kerakmi? Vazifa 3 (Chiroyli quti) namunasi
<!DOCTYPE html> <html> <head> <style> .quti { background: #E0EAFC; padding: 24px; border: 3px solid #2A6FDB; border-radius: 14px; width: 250px; } </style> </head> <body> <div class="quti">Men chiroyli qutiman! 📦</div> </body> </html>

Buni nusxalab, ranglar va o'lchamlarni o'zgartirib boshqa vazifalarni ham bajar!

Uy vazifasidan kattaroq — bu haqiqiy loyihalar! Har birida bugun o'rganganingni (selektor, rang, shrift, box model, o'lcham) birga ishlatasan. Yangi index.html och, kodni yoz va brauzerda ko'r! 🎨

☕ OSON

Tashrif kartasi (Business Card)

O'zing haqingda chiroyli karta yasa. Bitta <div> ichida isming (<h2>), kasbing (<p>) va bitta iqtibos bo'lsin. Qutiga fon, padding, burchak va soya ber!

🌈 background 📦 padding ⬭ border-radius ↔️ text-align 📏 width
🎯 Bonus: qutiga box-shadow qo'shib "suzayotgan" ko'rinish ber.
📄 To'liq kod — nusxalab brauzerda och
tashrif-kartasi.html
<!DOCTYPE html>
<html>
<head>
  <style>
    body {
      background: #FCE7F3;          /* sahifa foni */
      display: flex;
      justify-content: center;
      padding-top: 60px;
    }
    .karta {
      background: #E84CA0;
      color: white;
      width: 260px;
      padding: 26px;
      border-radius: 18px;
      text-align: center;
      box-shadow: 0 12px 28px rgba(232,76,160,.4);
    }
    .karta h2 {
      font-size: 28px;
      margin: 0 0 4px;
    }
    .kasb {
      color: #FFD2EC;
      font-size: 16px;
      margin: 0 0 14px;
    }
    .iqtibos {
      font-size: 15px;
      font-style: italic;
    }
  </style>
</head>
<body>
  <div class="karta">
    <h2>Ali Valiyev</h2>
    <p class="kasb">Yosh dasturchi 💻</p>
    <p class="iqtibos">"Kodlash — bu sehr!"</p>
  </div>
</body>
</html>

🌤️ O'RTACHA

Rangli tugmalar to'plami

3 xil tugma yasa: <button>larga class ber — .yashil, .qizil, .kok. Har biri har xil rangda bo'lsin. Bu — class selektorini mashq qilish!

🎯 .class selektor 🌈 background + color 📦 padding ⬭ border-radius
🎯 Bonus: hamma tugmaga umumiy button { } selektori bilan bir xil padding ber, rangni faqat class'lar orqali o'zgartir.
📄 To'liq kod — nusxalab brauzerda och
tugmalar.html
<!DOCTYPE html>
<html>
<head>
  <style>
    button {                    /* HAMMA tugmaga umumiy */
      padding: 12px 24px;
      border: none;
      border-radius: 30px;
      color: white;
      font-size: 16px;
      font-weight: bold;
      cursor: pointer;
      margin: 6px;
    }
    .yashil { background: #16A34A; }   /* class bilan rang */
    .qizil  { background: #E84CA0; }
    .kok    { background: #2A6FDB; }
  </style>
</head>
<body>
  <button class="yashil">Saqlash</button>
  <button class="qizil">O'chirish</button>
  <button class="kok">Yuborish</button>
</body>
</html>

🔥 QIYINROQ

"Mening sevimlim" plakati

Sevimli o'yin, film yoki jamoang haqida plakat yasa. Katta sarlavha (<h1>), 2-3 ta paragraf va bitta rangli quti bo'lsin. Turli font-size, font-family va ranglardan foydalan — hamma narsani birlashtir!

🔤 font-size + font-family 🎯 id + class 📦 box model 🌈 rang va fon
🎯 Bonus: butun sahifa foni (body { background })ni ham o'zgartir, plakat markazda tursin.
📄 To'liq kod — nusxalab brauzerda och
plakat.html
<!DOCTYPE html>
<html>
<head>
  <style>
    body {
      background: #FEF3C7;
      text-align: center;
      font-family: Georgia, serif;
    }
    #sarlavha {
      font-size: 48px;
      color: #D9730A;
      font-family: 'Trebuchet MS', sans-serif;
    }
    .tavsif {
      font-size: 20px;
      color: #92400E;
      line-height: 1.6;
    }
    .quti {
      background: #D9730A;
      color: white;
      width: 320px;
      margin: 24px auto;          /* markazga qo'yadi */
      padding: 22px;
      border-radius: 16px;
      font-size: 18px;
    }
  </style>
</head>
<body>
  <h1 id="sarlavha">Mening sevimlim ⚽</h1>
  <p class="tavsif">Men futbolni juda yaxshi ko'raman.</p>
  <p class="tavsif">U jamoa ruhini va mehnatni o'rgatadi.</p>
  <div class="quti">
    "Har bir o'yin — yangi imkoniyat!" 🌟
  </div>
</body>
</html>
