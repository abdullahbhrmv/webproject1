QISM 1

Nega bu o'yin o'rta darajada?

Mevalarni Yig' — 1-o'yindan uch narsa bilan farq qiladi: birinchidan, ekranda bir emas, bir nechta obyekt bo'ladi (buni arrayda saqlaymiz). Ikkinchidan, foydalanuvchi sichqoncha bosishi o'rniga klaviaturada tugmani bosib turadi — bu butunlay boshqa turdagi hodisa. Uchinchidan, obyektlar o'zlari harakatlanadi — buning uchun o'yin sikli kerak bo'ladi, u soniyada 60 marta ekranni qayta chizadi.

Bu uchtasi — array, davomli klaviatura boshqaruvi va o'yin sikli — deyarli barcha haqiqiy o'yinlarning (Mario, Flappy Bird, Subway Surfers) yuragida yotadi. Shu sababli bu darsni "o'rta daraja" deb ataymiz.

🏆

Maqsad: darsni tugatgach, sen bir vaqtning o'zida harakatlanadigan ko'plab obyektlarni boshqara oladigan o'yin yasashni bilib olasan — bu keyingi, qiyin darajadagi o'yin uchun asos bo'ladi.

🧠

O'yin "miyasi" qanday ishlaydi?

Bu o'yin ortida to'rt bosqichli mantiq yotadi — va ular doim aylanib takrorlanadi:

1️⃣ Boshqarish

keydown tugma bosilganini, keyup esa qo'yib yuborilganini biladi. Biz bu holatni o'zgaruvchida saqlab turamiz.

2️⃣ Yaratish

Har 1-1.5 soniyada setInterval yangi meva (yoki bomba) yasab, uni arrayga qo'shadi.

3️⃣ Harakat sikli

requestAnimationFrame soniyada ~60 marta ishlaydi: savatni suradi, har bir mevani birmuncha pastga tushiradi.

4️⃣ To'qnashish

Har karrasida meva savat bilan to'qnashdimi deb tekshiriladi. To'qnashsa — ball yoki jon o'zgaradi.

CSS — savat va mevalarga "erkinlik" beramiz

1-o'yindagidek, harakatlanuvchi hamma narsaga position: absolute beramiz. Farqi shundaki, bu safar ikki xil harakatlanuvchi obyektimiz bor — biri gorizontal (savat), boshqasi vertikal (meva):

style.css
.maydon {
  position: relative;
  width: 480px;
  height: 340px;
  overflow: hidden; /* meva tashqariga chiqmasin */
}

.savat {
  position: absolute;
  bottom: 8px; /* doim pastda turadi */
  width: 56px;
  font-size: 42px;
  /* left qiymatini JS o'zgartirib turadi */
}

.meva {
  position: absolute;
  top: -40px; /* osmondan boshlanadi */
  width: 40px;
  font-size: 34px;
  /* top qiymatini JS pasaytirib turadi */
}
.savatbottom doim bir xil — faqat left o'zgaradi, shuning uchun savat faqat gorizontal yuradi.
.mevatop: -40pxdan boshlanadi (maydondan tashqarida, ko'rinmas holda), keyin JS uni pastga suradi.
overflow: hiddenMeva pastga tushib maydondan chiqib ketganda, uni ko'rinmaydigan qilib "kesib tashlaydi".
3

JavaScript — o'yin siklini quramiz

1. Klaviatura bilan savatni harakatlantirish

Sichqoncha bosishdan farqli o'laroq, klaviaturada tugma bosilgan holatda turishi mumkin. Shuning uchun bosilgan/bosilmaganini ikki o'zgaruvchida saqlab qo'yamiz, harakatni esa keyinroq, sikl ichida bajaramiz:

script.js
let chapga = false;
let ongga = false;

document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowLeft") chapga = true;
  if (e.key === "ArrowRight") ongga = true;
});

document.addEventListener("keyup", (e) => {
  if (e.key === "ArrowLeft") chapga = false;
  if (e.key === "ArrowRight") ongga = false;
});
keydownTugma bosilgan zahoti bir marta ishlaydi — biz shu payt bayroqni true qilamiz.
keyupTugma qo'yib yuborilganda bayroqni qayta falsega qaytaradi.
e.keyQaysi tugma bosilganini aytadi — "ArrowLeft", "ArrowRight" va h.k.

2. Mevalarni yaratish va tushirish

Har mevani arrayda saqlaymiz — chunki bir vaqtda bir nechtasi bo'lishi mumkin, va har birining o'z holati (elementi, x/y koordinatasi) bor:

script.js
let mevalar = []; // hozir ekrandagi barcha mevalar

function mevaYarat() {
  const maydon = document.getElementById("maydon");
  const bombaMi = Math.random() < 0.22;
  const el = document.createElement("div");
  el.className = "meva";
  el.textContent = bombaMi ? "💣" : "🍎";
  const x = Math.random() * (maydon.clientWidth - 40);
  el.style.left = x + "px";
  maydon.appendChild(el);
  mevalar.push({ el, x, y: -40, bomba: bombaMi });
}

setInterval(mevaYarat, 1200); // har 1.2 soniyada bitta yangi meva
document.createElementHTML faylida yozilmagan yangi <div>ni JS orqali "yaratib" beradi.
mevalar.push(...)Har yangi mevani array oxiriga qo'shadi — shu bilan qancha meva bor ekanini "eslab qolamiz".
{ el, x, y, bomba }Bitta meva haqidagi barcha ma'lumot — elementi, koordinatasi va turi — bitta obyektda.

3. O'yin sikli — requestAnimationFrame

Bu — bu darsning eng muhim tushunchasi. requestAnimationFrame berilgan funksiyani soniyada taxminan 60 marta chaqiradi — xuddi filmning kadrlari kabi. Har chaqirilganda biz savatni suramiz va har bir mevani bir oz pastga tushiramiz:

script.js
let savatX = 210;

function oyinSikli() {
  const savat = document.getElementById("savat");
  if (chapga) savatX -= 6;
  if (ongga) savatX += 6;
  savat.style.left = savatX + "px";

  mevalar.forEach((m) => {
    m.y += 2.5; // har kadrda pastga tushadi
    m.el.style.top = m.y + "px";
  });

  requestAnimationFrame(oyinSikli); // keyingi kadrni so'raymiz
}

oyinSikli(); // siklni ishga tushiramiz
requestAnimationFrame(oyinSikli)Funksiya o'zini-o'zi qayta chaqiradi — shu tarzda sikl to'xtamay davom etadi.
m.y += 2.5Har kadrda mevaning "pastga tushish tezligi" — shu son katta bo'lsa, meva tezroq tushadi.
forEachArray ichidagi har bir meva uchun bir xil amalni takrorlaydi.

4. To'qnashishni aniqlash va qiyinlashtirish

Oxirgi qadam — mevaning savatga tegib ketganini tekshirish (bu "kolliziya" deyiladi) va vaqt o'tishi bilan o'yinni tezlashtirish:

script.js
function toqnashdimi(meva) {
  const savatOsti = 340 - 46; // savatning yuqori chegarasi
  const gorizontalMosKeladi = meva.x < savatX + 56 && meva.x + 40 > savatX;
  return meva.y + 40 >= savatOsti && gorizontalMosKeladi;
}

// har 5 soniyada o'yin biroz qiyinlashadi
setInterval(() => {
  tushishTezligi += 0.3;
}, 5000);
meva.x < savatX+56 && ...Ikki to'rtburchak gorizontal ustma-ust tushganini tekshiradi — bu "qutilar to'qnashuvi" usuli.
meva.y+40 >= savatOstiMeva pastga yetib, savat balandligiga tegib-tegmaganini tekshiradi.
tushishTezligi += 0.3Vaqt o'tishi bilan tezlikni oshirib, o'yinni tobora qiyinlashtiradi.

⚙️ script.js
script.js
let ball = 0;
let jon = 3;
let ishlayapti = false;
let savatX = 210;
let chapga = false;
let ongga = false;
let mevalar = [];
let tushishTezligi = 2.5;
let yaratishTaymer, qiyinlashtirishTaymer;

document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowLeft") chapga = true;
  if (e.key === "ArrowRight") ongga = true;
});
document.addEventListener("keyup", (e) => {
  if (e.key === "ArrowLeft") chapga = false;
  if (e.key === "ArrowRight") ongga = false;
});

function mevaYarat() {
  const maydon = document.getElementById("maydon");
  const bombaMi = Math.random() < 0.22;
  const el = document.createElement("div");
  el.className = "meva";
  el.textContent = bombaMi ? "💣" : ["🍎","🍊","🍇","🍓"][Math.floor(Math.random()*4)];
  const x = Math.random() * (maydon.clientWidth - 40);
  el.style.left = x + "px";
  maydon.appendChild(el);
  mevalar.push({ el, x, y: -40, bomba: bombaMi });
}

function toqnashdimi(m) {
  const savatOsti = 340 - 46;
  const mos = m.x < savatX + 56 && m.x + 40 > savatX;
  return m.y + 40 >= savatOsti && mos;
}

function oyinSikli() {
  if (!ishlayapti) return;
  const savat = document.getElementById("savat");
  if (chapga) savatX -= 6;
  if (ongga) savatX += 6;
  savatX = Math.max(0, Math.min(424, savatX));
  savat.style.left = savatX + "px";

  for (let i = mevalar.length - 1; i >= 0; i--) {
    const m = mevalar[i];
    m.y += tushishTezligi;
    m.el.style.top = m.y + "px";

    if (toqnashdimi(m)) {
      if (m.bomba) { jon--; document.getElementById("jon").textContent = "❤️".repeat(Math.max(jon,0)); }
      else { ball++; document.getElementById("ball").textContent = ball; }
      m.el.remove();
      mevalar.splice(i, 1);
      if (jon <= 0) { tugat(); return; }
    } else if (m.y > 340) {
      m.el.remove();
      mevalar.splice(i, 1);
    }
  }
  requestAnimationFrame(oyinSikli);
}

function boshla() {
  ball = 0; jon = 3; savatX = 210; tushishTezligi = 2.5; ishlayapti = true;
  document.getElementById("ball").textContent = 0;
  document.getElementById("jon").textContent = "❤️❤️❤️";
  mevalar.forEach(m => m.el.remove());
  mevalar = [];
  clearInterval(yaratishTaymer);
  clearInterval(qiyinlashtirishTaymer);
  yaratishTaymer = setInterval(mevaYarat, 1200);
  qiyinlashtirishTaymer = setInterval(() => { tushishTezligi += 0.3; }, 5000);
  oyinSikli();
}

function tugat() {
  ishlayapti = false;
  clearInterval(yaratishTaymer);
  clearInterval(qiyinlashtirishTaymer);
  alert("💥 O'yin tugadi! Ball: " + ball);
}
🔍 Diqqat qil
for (let i = mevalar.length-1; i>=0; i--)Array bo'ylab oxiridan boshlab yuramiz — chunki ichida elementlarni splice bilan o'chiryapmiz.
ishlayaptiSikl to'xtovsiz o'zini chaqiraveradi — shu bayroq false bo'lgach, sikl to'xtaydi.

Uchala kodni nusxalab, mos nomlar bilan saqla (index.html, style.css, script.js), bitta papkaga joylashtir va index.htmlni ikki marta bos.
