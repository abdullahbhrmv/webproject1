QISM 1

Nega bu o'yin "Qiyin" daraja?

Bir emas — uchta harakatlanuvchi guruh

Oldingi o'yinlarda ekranda bitta turdagi narsa tushardi. Bu safar 3 ta alohida massiv bir vaqtda yashaydi:

  • lazerlar = [] — kemangdan chiqib tepaga uchuvchi ko'k lazerlar.
  • dushmanlar = [] — osmondan zikzak qilib tushuvchi kelgindilar va asteroidlar.
  • dushmanLazerlari = [] — dushman senga nishon olib otadigan qizil lazerlar.

Uchta xil to'qnashuv (kolliziya)

QISM 2

O'yin "miyasi" qanday ishlaydi?

1. Koordinatalar tizimi — nol qayerda?

Brauzerda (0, 0) nuqta — chap yuqori burchak. x o'nga qarab, y esa pastga qarab o'sadi. Shuning uchun kemani tepaga ko'tarish uchun kemaY -= 5 deb ayiramiz, pastga tushirish uchun esa += qilamiz. Matematika darsidagidan teskari — buni yodda tut!

Har bir obyekt shunchaki ikkita son: x va y. Biz JavaScriptda shu sonlarni o'zgartiramiz, keyin CSS'ning left va top xossalariga yozamiz. Ekrandagi harakat — aslida shu.

2. O'yin sikli (Game Loop) — o'yinning yuragi

O'yin "bir marta ishlab to'xtaydigan" dastur emas. U sekundiga ~60 marta qayta-qayta ishlaydigan bitta funksiya. Har bir aylanish kadr (frame) deb ataladi — xuddi multfilmdagi kabi:

script.js
function oyinSikli() {
  if (!ishlayapti) return;   // o'yin tugagan bo'lsa — to'xtaymiz

  // 1) Bosilgan tugmalarga qarab kemani suramiz
  // 2) Ko'k lazerlarni tepaga suramiz
  // 3) Qizil lazerlarni kemaga qarab suramiz + tegdimi deb tekshiramiz
  // 4) Dushmanlarni zikzak tushiramiz + 3 xil to'qnashuvni tekshiramiz
  // 5) Maydondan chiqib ketganlarni o'chiramiz

  requestAnimationFrame(oyinSikli);  // va yana o'zini chaqiradi!
}
💡

setInterval emas, requestAnimationFrame! Farqi: setInterval ekran tayyormi-yo'qmi baribir ishlayveradi, requestAnimationFrame esa brauzer ekranni yangilaydigan aniq paytda chaqiriladi. Natijada harakat silliq bo'ladi va boshqa tabda turganda batareyani yemaydi.

3. Tugmalar holati — nega obyekt?

❌ Eski usul

Har bir tugma uchun alohida o'zgaruvchi: chapBosildi, ongBosildi, tepaBosildi... 5 ta tugma = 5 ta o'zgaruvchi va 10 ta if.

✅ Yangi usul

Bitta obyekt: tugmalar = {}. Bosilganda tugmalar["ArrowLeft"] = true, qo'yib yuborilganda false. Nechta tugma bo'lsa ham kod uzunligi o'zgarmaydi.

Bu usulning yana bitta kuchli tomoni bor: bir vaqtda bir nechta tugmani ushlab turish mumkin. ↑ va → ni birga bossang, kema diagonal uchadi — chunki sikl ichida ikkala if ham bajariladi.

4. Zikzak harakat — matematika o'yinni "tirik" qiladi

Dushman shunchaki y += 2.5 qilib tushsa, o'yin zerikarli bo'ladi. Biz uning X koordinatasini sinus to'lqini bilan tebratamiz. Math.sin() har doim −1 bilan +1 orasida son qaytaradi — xuddi arg'imchoq kabi oldinga-orqaga.

script.js
d.x = d.baseX + Math.sin(d.y / 30) * 40;
//    |         |                |    |
//    |         |                |    +-- 40 = tebranish KENGLIGI (piksel)
//    |         |                +------- 30 = to'lqin UZUNLIGI (katta son = yumshoq)
//    |         +------------------------ y o'zgargani sari sinus aylanadi
//    +---------------------------------- baseX = tug'ilgan paytdagi joyi
🧪

Ikkala sonni o'zgartirib ko'r: 40 ni 90 qilsang dushman ekranni kesib o'tadi; 30 ni 8 qilsang esa u titraydigan bo'lib qoladi.

5. Nishonga otish — vektor nima?

Dushman lazerini shunchaki pastga tushirish oson. Ammo biz uni kemaga qarab uchirmoqchimiz. Buning uchun dushmandan kemagacha bo'lgan yo'nalishni topamiz va uni normallashtiramiz (uzunligini 1 ga keltiramiz), so'ng kerakli tezlikka ko'paytiramiz:

script.js
const dx = kemaX - x;              // gorizontal farq
const dy = kemaY - y;              // vertikal farq
const uzunlik = Math.hypot(dx, dy); // to'g'ri masofa (Pifagor teoremasi!)

const vx = dx / uzunlik * 4;       // 1 kadrda X bo'yicha necha piksel
const vy = dy / uzunlik * 4;       // 1 kadrda Y bo'yicha necha piksel

Math.hypot(dx, dy) — bu maktabdagi a² + b² = c² formulasining tayyor ko'rinishi. dx va dy ni shu masofaga bo'lsak, yo'nalish saqlanadi, lekin uzunlik 1 ga tushadi. Keyin * 4 qilsak — lazer qaysi tomonga uchmasin, doim bir xil tezlikda uchadi.

6. To'qnashuv — AABB usuli

Kompyuter 🚀 va 👾 rasmlarini "ko'rmaydi". U faqat to'rtburchaklarni biladi. Ikkita to'rtburchak kesishganini tekshirishning eng oson yo'li — AABB (Axis-Aligned Bounding Box):

script.js
function toqnashuv(x1, y1, w1, h1, x2, y2, w2, h2) {
  return x1 < x2 + w2 &&   // 1-chi 2-chining o'ng chetidan chapdami?
         x1 + w1 > x2 &&   // 1-chi 2-chining chap chetidan o'ngdami?
         y1 < y2 + h2 &&   // 1-chi 2-chining pastidan tepadami?
         y1 + h1 > y2;     // 1-chi 2-chining tepasidan pastdami?
}

To'rttala shart birdaniga bajarilsa — to'qnashuv bor. Bitta shart yolg'on bo'lsa — ular tegmagan.

⚠️

Emoji 40×40 katakda tursa ham, uning chizilgan qismi ancha kichik. Agar 40×40 ni to'liq ishlatsak, o'yinchi "tegmagan" lazerdan o'ladi va bu adolatsiz tuyuladi. Shuning uchun biz to'qnashuv uchun 24×24 lik kichikroq "tana" ishlatamiz. O'yin dasturchilari buni hitbox deb ataydi.

3. Bizning lazer + otish tezligiga cheklov

4. Dushman lazeri — nishonga olish matematikasi

script.js
// ====== 4. DUSHMAN LAZERI — NISHONGA QARAB ======
function dushmanLazerOtish(ex, ey) {
  const el = document.createElement("div");
  el.className = "lazer";
  el.style.background = "#EF4444";
  el.style.boxShadow = "0 0 10px #EF4444";

  const x = ex + 17;
  const y = ey + OLCHAM;

  // Dushmandan kemaning markazigacha bo'lgan yo'nalish
  const dx = (kemaX + OLCHAM / 2) - x;
  const dy = (kemaY + OLCHAM / 2) - y;
  const uzunlik = Math.hypot(dx, dy) || 1;   // 0 ga bo'lmaslik uchun
  const tezlik = 4;

  el.style.left = x + "px";
  el.style.top = y + "px";
  // lazerni uchish yo'nalishi bo'ylab burib qo'yamiz
  el.style.transform = "rotate(" + Math.atan2(-dx, dy) + "rad)";

    el, x, y,
    vx: dx / uzunlik * tezlik,   // 1 kadrda X bo'yicha siljish

}
Kod nima qilyapti?

Math.hypot(dx, dy)To'g'ri masofa: √(dx² + dy²). Pifagor teoremasining tayyor ko'rinishi.
|| 1Himoya. Agar masofa 0 chiqsa (dushman aynan kema ustida), nolga bo'linish NaN beradi va lazer g'oyib bo'ladi.

// ====== 7. O'YIN SIKLI — sekundiga ~60 marta ======
function oyinSikli() {
  if (!ishlayapti) return;

  // Maydon o'lchami telefon va kompyuterda har xil bo'ladi,
  // shuning uchun chegarani HAR KADRDA qaytadan hisoblaymiz.
  const engOng = maydon.clientWidth - OLCHAM;
  const engPast = maydon.clientHeight - OLCHAM;

  // --- 7.1 Kema harakati ---
  if (tugmalar["ArrowLeft"])  kemaX -= 5;
  if (tugmalar["ArrowRight"]) kemaX += 5;
  if (tugmalar["ArrowUp"])    kemaY -= 5;
  if (tugmalar["ArrowDown"])  kemaY += 5;

  kemaX = Math.max(0, Math.min(engOng, kemaX));
  kemaY = Math.max(0, Math.min(engPast, kemaY));

  const kema = document.getElementById("kema");
  kema.style.left = kemaX + "px";
  kema.style.top = kemaY + "px";

  // --- 7.2 Bizning lazerlar tepaga uchadi ---
  for (let i = lazerlar.length - 1; i >= 0; i--) {
    const l = lazerlar[i];
    l.y -= 8;
    l.el.style.top = l.y + "px";

    if (l.y < -20) {                 // ekrandan chiqib ketdi
      l.el.remove();
      lazerlar.splice(i, 1);
    }
  }

  // --- 7.3 Qizil lazerlar kemaga qarab uchadi ---
  for (let i = dushmanLazerlari.length - 1; i >= 0; i--) {
    const dl = dushmanLazerlari[i];
    dl.x += dl.vx;
    dl.y += dl.vy;
    dl.el.style.left = dl.x + "px";
    dl.el.style.top = dl.y + "px";

    if (toqnashuv(dl.x, dl.y, 6, 20,
                  kemaX + CHET, kemaY + CHET, TANA, TANA)) {
      dl.el.remove();
      dushmanLazerlari.splice(i, 1);
      jonKamaytir();
      if (!ishlayapti) return;       // oxirgi jon edimi?
      continue;
    }

    if (dl.y > maydon.clientHeight || dl.y < -20 ||
        dl.x < -20 || dl.x > maydon.clientWidth) {
      dl.el.remove();
      dushmanLazerlari.splice(i, 1);
    }
  }

  // --- 7.4 Dushmanlar zikzak tushadi ---
  for (let i = dushmanlar.length - 1; i >= 0; i--) {
    const d = dushmanlar[i];

    d.y += 2.5;
    d.x = d.baseX + Math.sin(d.y / 30) * 40;
    d.x = Math.max(0, Math.min(engOng, d.x));
    d.el.style.top = d.y + "px";
    d.el.style.left = d.x + "px";

    // har kadrda 2% ehtimol bilan otadi
    if (Math.random() < 0.02 && d.y > 0 && d.y < maydon.clientHeight - 120) {
      dushmanLazerOtish(d.x, d.y);
    }

    if (d.y > maydon.clientHeight) {   // pastga tushib ketdi
      d.el.remove();
      dushmanlar.splice(i, 1);
      continue;
    }

    // (a) dushman kemaga urildimi?
    if (toqnashuv(d.x + CHET, d.y + CHET, TANA, TANA,
                  kemaX + CHET, kemaY + CHET, TANA, TANA)) {
      d.el.remove();
      dushmanlar.splice(i, 1);
      jonKamaytir();
      if (!ishlayapti) return;
      continue;
    }

    // (b) bizning lazer dushmanga tegdimi?
    for (let j = lazerlar.length - 1; j >= 0; j--) {
      const l = lazerlar[j];

      if (toqnashuv(d.x + CHET, d.y + CHET, TANA, TANA, l.x, l.y, 6, 20)) {
        ball += 10;
        document.getElementById("ball").textContent = ball;

        const portlash = d.el;
        portlash.textContent = "💥";
        setTimeout(() => portlash.remove(), 100);
        dushmanlar.splice(i, 1);

        l.el.remove();
        lazerlar.splice(j, 1);
        break;                        // bu dushman allaqachon o'ldi
      }
    }
  }

  kadr = requestAnimationFrame(oyinSikli);
}

  if (tugmalar["ArrowRight"]) kemaX += 5;
  if (tugmalar["ArrowUp"])    kemaY -= 5;
  if (tugmalar["ArrowDown"])  kemaY += 5;

  kemaX = Math.max(0, Math.min(engOng, kemaX));
  kemaY = Math.max(0, Math.min(engPast, kemaY));

  const kema = document.getElementById("kema");
  kema.style.left = kemaX + "px";
  kema.style.top = kemaY + "px";

  // --- 7.2 Bizning lazerlar tepaga uchadi ---
  for (let i = lazerlar.length - 1; i >= 0; i--) {
    const l = lazerlar[i];
    l.y -= 8;
    l.el.style.top = l.y + "px";

    if (l.y < -20) {                 // ekrandan chiqib ketdi
      l.el.remove();
      lazerlar.splice(i, 1);
    }
  }

  // --- 7.3 Qizil lazerlar kemaga qarab uchadi ---
  for (let i = dushmanLazerlari.length - 1; i >= 0; i--) {
    const dl = dushmanLazerlari[i];
    dl.x += dl.vx;
    dl.y += dl.vy;
    dl.el.style.left = dl.x + "px";
    dl.el.style.top = dl.y + "px";

    if (toqnashuv(dl.x, dl.y, 6, 20,
                  kemaX + CHET, kemaY + CHET, TANA, TANA)) {
      dl.el.remove();
      dushmanLazerlari.splice(i, 1);
      jonKamaytir();
      if (!ishlayapti) return;       // oxirgi jon edimi?
      continue;
    }

    if (dl.y > maydon.clientHeight || dl.y < -20 ||
        dl.x < -20 || dl.x > maydon.clientWidth) {
      dl.el.remove();
      dushmanLazerlari.splice(i, 1);
    }
  }

  // --- 7.4 Dushmanlar zikzak tushadi ---
  for (let i = dushmanlar.length - 1; i >= 0; i--) {
    const d = dushmanlar[i];

    d.y += 2.5;
    d.x = d.baseX + Math.sin(d.y / 30) * 40;
    d.x = Math.max(0, Math.min(engOng, d.x));
    d.el.style.top = d.y + "px";
    d.el.style.left = d.x + "px";

    // har kadrda 2% ehtimol bilan otadi
    if (Math.random() < 0.02 && d.y > 0 && d.y < maydon.clientHeight - 120) {
      dushmanLazerOtish(d.x, d.y);
    }

    if (d.y > maydon.clientHeight) {   // pastga tushib ketdi
      d.el.remove();
      dushmanlar.splice(i, 1);
      continue;
    }

    // (a) dushman kemaga urildimi?
    if (toqnashuv(d.x + CHET, d.y + CHET, TANA, TANA,
                  kemaX + CHET, kemaY + CHET, TANA, TANA)) {
      d.el.remove();
      dushmanlar.splice(i, 1);
      jonKamaytir();
      if (!ishlayapti) return;
      continue;
    }

    // (b) bizning lazer dushmanga tegdimi?
    for (let j = lazerlar.length - 1; j >= 0; j--) {
      const l = lazerlar[j];

      if (toqnashuv(d.x + CHET, d.y + CHET, TANA, TANA, l.x, l.y, 6, 20)) {
        ball += 10;
        document.getElementById("ball").textContent = ball;

        const portlash = d.el;
        portlash.textContent = "💥";
        setTimeout(() => portlash.remove(), 100);
        dushmanlar.splice(i, 1);

        l.el.remove();
        lazerlar.splice(j, 1);
        break;                        // bu dushman allaqachon o'ldi
      }
    }
  }

  kadr = requestAnimationFrame(oyinSikli);
}

// ====== 8. JON KAMAYISHI ======
function jonKamaytir() {
  jon--;
  document.getElementById("jon").textContent = "❤️".repeat(Math.max(jon, 0));

  maydon.classList.add("zarba");                          // qizil chaqnash
  setTimeout(() => maydon.classList.remove("zarba"), 250);

  if (jon <= 0) tugat();
}

// ====== 9. BOSHLASH VA TUGATISH ======
function boshla() {
  ball = 0;
  jon = 3;
  ishlayapti = true;
  kemaX = 220;
  kemaY = 360;
  tugmalar = {};
  oxirgiOtish = 0;

  document.getElementById("ball").textContent = 0;
  document.getElementById("jon").textContent = "❤️❤️❤️";
  document.getElementById("tugadi").style.display = "none";
  document.getElementById("boshlaBtn").style.display = "none";

  // Eski o'yindan qolgan barcha elementlarni tozalaymiz
  [...lazerlar, ...dushmanlar, ...dushmanLazerlari].forEach(v => v.el.remove());
  lazerlar = [];
  dushmanlar = [];
  dushmanLazerlari = [];

  // MUHIM: eski sikllarni to'xtatamiz.
  // Aks holda ikkita sikl birga ishlab, o'yin 2 barobar tezlashadi!
  clearInterval(taymer);
  cancelAnimationFrame(kadr);

  taymer = setInterval(dushmanYarat, 1200);
  oyinSikli();
}

function tugat() {
  ishlayapti = false;
  clearInterval(taymer);
  cancelAnimationFrame(kadr);

  document.getElementById("natija").textContent = ball;
  document.getElementById("tugadi").style.display = "flex";
  document.getElementById("boshlaBtn").style.display = "inline-block";
}
