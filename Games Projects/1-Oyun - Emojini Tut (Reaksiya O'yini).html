Birinchi o'yinimiz: Emojini Tut!

Bugun HTML, CSS va JavaScript yordamida haqiqiy o'yin yasaymiz — ekranda sakrab yuruvchi emojini sichqoncha bilan bosib, vaqt tugagunicha ball to'playsan. Bu bizning 3 ta o'yin seriyamizning birinchisi — keyingi darslarda o'rta va qiyin o'yinlarga o'tamiz. 👇

Hozirgacha kalkulyator va xatolarni ushlashni o'rgandik. Endi shu bilimlarni ishlatib, o'yin yasaymiz! O'yin — bu shunchaki 3 narsa: ekranda nimadir ko'rinadi, foydalanuvchi unga ta'sir qiladi (bosadi), va dastur natijani hisoblaydi (ball, vaqt). Kelinglar, qadam-baqadam quramiz.

QISM 1

Nega aynan shu o'yin?

Emojini Tut — reaksiya (tezkorlik) o'yini: ekranda bitta emoji tasodifiy joyda paydo bo'ladi, sen uni bossang — ball olasan va u yana boshqa joyga "sakraydi". 20 soniya ichida imkon qadar ko'proq bosishga harakat qilasan.

Bu o'yin basit daraja uchun tanlandi, chunki u faqat 3 ta asosiy dasturlash tushunchasidan iborat: tasodifiy son, bosish hodisasi (click) va vaqt hisoblagichi. Keyingi darslarda — o'rta darajada nishonlar ko'payadi va tezlashadi, qiyin darajada esa to'liq o'yin maydoni, to'siqlar va darajalar paydo bo'ladi.

🏆

Maqsad: bugungi darsni tugatgach, sen o'zing yasagan o'yinni do'stlaringga yuborib, kim ko'proq ball to'plashini tekshirib ko'rishing mumkin!

🧠

O'yin "miyasi" qanday ishlaydi?

Har qanday shu turdagi o'yin ortida bitta oddiy mantiq yotadi:

1️⃣ Joylashtirish

Emoji o'yin maydonining tasodifiy nuqtasiga qo'yiladi — buni Math.random() hisoblab beradi.

2️⃣ Bosish

Foydalanuvchi bossa — onclick ishga tushadi: ball +1, va emoji yana yangi tasodifiy joyga ko'chadi.

3️⃣ Vaqt

setInterval har soniyada ishlab, hisoblagichni kamaytiradi. Nolga yetganda — o'yin tugaydi.

4️⃣ Yakun

Vaqt tugaganda oxirgi ball ekranga chiqadi va "Qayta boshlash" tugmasi ko'rinadi.

2

CSS — nishonni "erkin" qilamiz

Emoji maydon ichida istalgan joyga ko'chib yurishi uchun, unga position: absolute beramiz — bu uni oddiy oqimdan chiqarib, top va left qiymatlari bilan istalgan nuqtaga qo'yish imkonini beradi:

style.css
.maydon {
  /* nishon shu qutidan tashqariga chiqmasligi uchun */
  position: relative;
  width: 100%;
  height: 300px;
  background: #FFF1E2;
  border-radius: 20px;
  overflow: hidden;
}

.nishon {
  /* top/left bilan istalgan joyga qo'yish uchun */
  position: absolute;
  font-size: 46px;
  cursor: pointer;
}
position: relativeMaydonga qo'yiladi — shunda nishonning top/lefti shu maydonga nisbatan hisoblanadi.
position: absoluteNishonni erkin qo'yish uchun kerak — JS keyin uning top va leftini o'zgartiradi.
overflow: hiddenNishon hech qachon maydondan tashqariga "sakramasligi" uchun.
3

JavaScript — o'yinni jonlantiramiz

Tasodifiy joyga ko'chirish

script.js
function yangiJoy() {
  const maydon = document.getElementById("maydon");
  const nishon = document.getElementById("nishon");
  const x = Math.random() * (maydon.clientWidth - 60);
  const y = Math.random() * (maydon.clientHeight - 60);
  nishon.style.left = x + "px";
  nishon.style.top = y + "px";
}
Math.random()0 bilan 1 orasida tasodifiy son beradi — biz uni maydon o'lchamiga ko'paytiramiz.
clientWidth - 60Nishon maydondan tashqariga chiqib ketmasligi uchun uning o'lchamini ayirib tashlaymiz.

Bosish va vaqt hisoblagichi

script.js
let ball = 0, vaqt = 20, taymer;

function bosildi() {
  ball++;
  document.getElementById("ball").textContent = ball;
  yangiJoy();
}

function boshla() {
  ball = 0; vaqt = 20;
  yangiJoy();
  taymer = setInterval(() => {
    vaqt--;
    document.getElementById("vaqt").textContent = vaqt;
    if (vaqt <= 0) {
      clearInterval(taymer);
      alert("Vaqt tugadi! Ball: " + ball);
    }
  }, 1000);
}
setInterval(fn, 1000)Ichidagi kodni har 1000ms (1 soniya)da qayta-qayta ishga tushiradi.
clearInterval(taymer)Hisoblagichni to'xtatadi — bo'lmasa u abadiy ishlab, minusga tushib ketaveradi.
ball++Har bosishda ballni bittaga oshiradi.

⚙️ script.js
script.js
let ball = 0;
let vaqt = 20;
let taymer = null;

function yangiJoy() {
  const maydon = document.getElementById("maydon");
  const nishon = document.getElementById("nishon");
  const x = Math.random() * (maydon.clientWidth - 60);
  const y = Math.random() * (maydon.clientHeight - 60);
  nishon.style.left = x + "px";
  nishon.style.top = y + "px";
}

function bosildi() {
  ball++;
  document.getElementById("ball").textContent = ball;
  yangiJoy();
}

function boshla() {
  ball = 0;
  vaqt = 20;
  document.getElementById("ball").textContent = ball;
  document.getElementById("vaqt").textContent = vaqt;
  yangiJoy();
  clearInterval(taymer);
  taymer = setInterval(function() {
    vaqt--;
    document.getElementById("vaqt").textContent = vaqt;
    if (vaqt <= 0) {
      clearInterval(taymer);
      alert("⏰ Vaqt tugadi! Ball: " + ball);
    }
  }, 1000);
}

📒 Uy vazifasi

1. Emojini o'zingga yoqqan boshqasiga o'zgartir (masalan 🐸 o'rniga 🍕 yoki 👾).

2. O'yin vaqtini 20 dan 10 soniyaga tushir — qiyinroq bo'ladimi, sinab ko'r.

3. (Qo'shimcha, qiyinroq) Har bosishda nishonning font-sizeini bir oz kichraytirib bor — o'yin oxiriga borgan sari qiyinlashadi!
