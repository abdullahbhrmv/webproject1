Gradient — rang o'tishi

Oddiy rang o'rniga ikkita rang bir-biriga oqib o'tsa — bu gradient! Osmon kabi chiroyli. linear-gradient ishlatamiz.

📝 KOD
div {
  background: linear-gradient(
    to right, #E84CA0, #4C7DE8
  );
}

Hover — sichqoncha sehri

Hover = sichqonchani element ustiga olib borish. :hover bilan element ustiga kelganda o'zgaradi. 👇 Quyidagilarning ustiga sichqonchani olib bor!

🚀
Kattalashadi
🌀
Aylanadi
🎨
Rang o'zgaradi
div:hover {
  transform: scale(1.1);
}
💡

transition qo'shsang, o'zgarish silliq (smooth) bo'ladi — birdaniga emas, asta-sekin!

📄 To'liq kod — nusxalab brauzerda och
index.html
<!DOCTYPE html>
<html>
<head>
  <style>
    .tugma {
      width: 150px;
      padding: 20px;
      text-align: center;
      color: white;
      background: #E84CA0;
      border-radius: 14px;
      transition: transform 0.3s;   /* silliq o'zgarish */
    }
    .tugma:hover {
      transform: scale(1.1);        /* ustiga kelganda kattalashadi */
    }
  </style>
</head>
<body>
  <div class="tugma">Ustimga kel!</div>
</body>
</html>

Animatsiya — harakat!

Animatsiya — element o'z-o'zidan harakatlanadi! @keyframes bilan harakat yasab, animation bilan ulaymiz. Mana jonli misollar: 🎉

⚽
bounce 🏀
⭐
spin 🌀
💚
pulse 💗
🐶
wiggle 🤪
📝 KOD — sakraydigan to'p
@keyframes sakra {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-22px); }
  100% { transform: translateY(0); }
}

div {
  animation: sakra 1.2s infinite;
}
🎬 Sirini bilib ol:

0% — boshlanish, 50% — o'rtasi, 100% — oxiri. Element shu nuqtalar orasida silliq harakatlanadi. infinite = abadiy takrorlanadi! 🔁

📄 To'liq kod — nusxalab brauzerda och
index.html
<!DOCTYPE html>
<html>
<head>
  <style>
    @keyframes sakra {
      0%   { transform: translateY(0); }
      50%  { transform: translateY(-22px); }
      100% { transform: translateY(0); }
    }
    .top {
      width: 80px;
      height: 80px;
      background: #E84CA0;
      border-radius: 50%;
      animation: sakra 1.2s infinite;
    }
  </style>
</head>
<body>
  <div class="top"></div>
</body>
</html>

Uy vazifasi

Har bir vazifa uchun yangi index.html fayl yasa, <style> ichida CSS yoz va brauzerda ochib natijani ko'r! 🎨

1

🌈 Gradientli quti

Bitta <div> yasa va unga linear-gradient fon ber. Sevimli ikkita rangingni tanla — quyosh botishidek! 🌅

🎯 Maqsad: background: linear-gradient(...) ishlatish
2

⭕ Yumaloq tugma + soya

Bir quti yasa: border-radius bilan yumaloq qil va box-shadow bilan soya ber — go'yo ko'tarilib turgandek!

🎯 Maqsad: border-radius + box-shadow birga
3

👆 Sehrli hover tugma

Tugma yasa. Sichqoncha ustiga kelganda (:hover) u kattalashsin yoki rangini o'zgartirsin. transition qo'shib silliq qil!

🎯 Maqsad: :hover + transform + transition
⭐

🎁 Qo'shimcha (qiyinroq!) — Jonli kartochka

Hammasini birlashtir: gradient fonli, yumaloq, soyali kartochka yasa. Ichidagi emojini @keyframes bilan sakratib qo'y va kartani flex bilan o'rtaga joyla! 🎉

🎯 Maqsad: gradient + radius + shadow + animation + flex — hammasi birga!
