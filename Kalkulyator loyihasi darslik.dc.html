CSS display: grid

Kalkulyator tugmalarini jadval (qatorlar va ustunlar) qilib tizadi. grid-template-columns: repeat(4, 1fr) — "4 ta teng ustun yasa" degani. Xuddi telefondagi kalkulyatorday chiroyli tizilib qoladi! 🔲

🪄
Sehrli buyruq: eval()

eval() — matn ko'rinishidagi amalni oladi va hisoblab beradi! Masalan:

eval("2 + 3 * 4") // natija: 14 🪄

💡 Eslatma: katta dasturchilar eval o'rniga boshqa yo'l ishlatishadi, lekin o'rganish uchun u eng oson va sehrli! ✨

🔍 Kod qanday ishlaydi?
<input type="number">Son yoziladigan katakcha yasaydi. id beramiz — keyin topamiz.
.valueKatakchaga yozilgan narsani oladi. Lekin u matn bo'ladi ("8")!
Number(...)Matnni haqiqiy songa aylantiradi. Bo'lmasa "8"+"5" = "85" bo'lib qoladi! 😮
a + bIkki sonni qo'shadi va jami qutichasiga soladi.
.textContent = jamiNatijani <h1> ichiga yozib, ekranda ko'rsatadi.
⚠️

Eng muhim tuzoq! Number() yozishni unutma. Aks holda JavaScript sonlarni matn deb o'ylab, 8 + 5 ni "85" qilib qo'yadi! 🙈

2

To'rt amal

Endi 4 ta tugma qo'shamiz: +, −, ×, ÷. Qaysi tugmani bossang — JavaScript shu amalni bajaradi! Katakchalarga son yozib, amal tugmalarini bosib ko'r: 👇

{{ op2line }}
{{ res2 }}
📄 To'liq kod — nusxalab brauzerda och
tort-amal.html
<!DOCTYPE html>
<html>
<head>
  <!-- CSS — bezaklar alohida -->
  <style>
    body    { text-align:center; font-family:sans-serif; }
    input   { width:70px; font-size:22px; text-align:center; }
    .amallar{ display:flex; justify-content:center; gap:10px; margin:14px; }
    button  { font-size:22px; width:56px; height:56px; cursor:pointer; }
    #natija { font-size:44px; }
  </style>
</head>
<body>

  <h1>To'rt amal 🧮</h1>

  <input id="son1" type="number" value="12">
  <input id="son2" type="number" value="4">

  <div class="amallar">
    <button onclick="hisobla('+')">+</button>
    <button onclick="hisobla('-')">−</button>
    <button onclick="hisobla('*')">×</button>
    <button onclick="hisobla('/')">÷</button>
  </div>

  <h1 id="natija">?</h1>

  <script>
    // amal — qaysi tugma bosilganini bildiradi ('+','-','*','/')
    function hisobla(amal) {
      let a = Number(document.getElementById("son1").value);
      let b = Number(document.getElementById("son2").value);
      let javob;

      // SHART: qaysi amal ekanini tekshiramiz
      if (amal === '+') {
        javob = a + b;
      } else if (amal === '-') {
        javob = a - b;
      } else if (amal === '*') {
        javob = a * b;
      } else {
        javob = a / b;
      }

      document.getElementById("natija").textContent = javob;
    }
  </script>

</body>
</html>
🔍 Kod qanday ishlaydi?
hisobla('+')Bitta funksiya, lekin har tugma unga boshqa belgi beradi: '+', '-', '*', '/'.
function hisobla(amal)amal — bu qutichalik joy: ichiga bosilgan belgi tushadi.
if / else ifAmal qaysiligini tekshiradi va mos hisobni tanlaydi.
a * bKo'paytirish × emas, * bilan. Bo'lish esa / bilan!
else { a / b }Qolgan holatlarda (ya'ni ÷ bosilganda) bo'lish bajariladi.
💡

Diqqat qil: tugmada × yozilgan, lekin kod ichida *! Ekranda chiroyli belgi, kod ichida JavaScript tushunadigan belgi. 😎

Sinab ko'r: C — tozalash, ⌫ — bitta belgini o'chirish, ( ) — qavs bilan (2+3)×4 ham hisoblaydi! 🤯

📄 Haqiqiy kalkulyatorning to'liq kodi — nusxalab brauzerda och
haqiqiy-kalkulyator.html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family:sans-serif; text-align:center; background:#eee; }

    #ekran {
      background:#171426; color:white; font-size:40px;
      padding:20px; border-radius:14px; text-align:right;
      margin:0 auto 12px; width:280px; min-height:50px;
    }

    /* GRID — tugmalarni 4 ustunli jadval qilib tizadi */
    .tugmalar {
      display:grid;
      grid-template-columns: repeat(4, 1fr);  /* 4 teng ustun */
      gap:8px;
      width:300px; margin:0 auto;
    }
    button { font-size:22px; height:56px; border:none;
             border-radius:12px; cursor:pointer; }
    .amal { background:#FBBF24; color:white; }   /* + - * / */
    .teng { background:#16A34A; color:white; }   /* = */
  </style>
</head>
<body>

  <h1>Kalkulyator 🧮</h1>

  <!-- ekran: bosilgan narsa shu yerda ko'rinadi -->
  <div id="ekran">0</div>

  <div class="tugmalar">
    <button onclick="tozala()">C</button>
    <button onclick="yoz('7')">7</button>
    <button onclick="yoz('8')">8</button>
    <button onclick="yoz('9')">9</button>

    <button class="amal" onclick="yoz('/')">÷</button>
    <button onclick="yoz('4')">4</button>
    <button onclick="yoz('5')">5</button>
    <button onclick="yoz('6')">6</button>

    <button class="amal" onclick="yoz('*')">×</button>
    <button onclick="yoz('1')">1</button>
    <button onclick="yoz('2')">2</button>
    <button onclick="yoz('3')">3</button>

    <button class="amal" onclick="yoz('-')">−</button>
    <button onclick="yoz('0')">0</button>
    <button class="amal" onclick="yoz('+')">+</button>
    <button class="teng" onclick="hisobla()">=</button>
  </div>

  <script>
    // ekranda ko'rinadigan matn shu qutichada saqlanadi
    let matn = "";

    // tugma bosilganda ekranga qo'shamiz
    function yoz(belgi) {
      matn = matn + belgi;
      document.getElementById("ekran").textContent = matn;
    }

    // C — tozalash
    function tozala() {
      matn = "";
      document.getElementById("ekran").textContent = "0";
    }

    // = — hisoblash (eval sehri!)
    function hisobla() {
      let javob = eval(matn);       // matnli amalni hisoblaydi
      matn = "" + javob;            // javobni yana matnga aylantiramiz
      document.getElementById("ekran").textContent = javob;
    }
  </script>

</body>
</html>
🔍 Kod qanday ishlaydi? (hammasi birga!)
display: gridGRID: 16 ta tugmani 4 ustunli chiroyli jadval qilib tizadi.
let matn = ""O'zgaruvchi: ekrandagi yozuv shu bo'sh qutida saqlanadi.
yoz('7')Har tugma o'z belgisini beradi: matn = matn + belgi bilan ekranga qo'shiladi.
tozala()C tugmasi qutini bo'shatadi va ekranni "0" qiladi.
eval(matn)SEHR: "7*8" degan matnni oladi va 56 deb hisoblab beradi! 🪄

VAQTI KELDI

Uy vazifasi

Har vazifa uchun yangi kalkulyator.html yasa. Bugun o'rgangan narsalarni ishlat: .value, Number(), * /, grid, eval(). 🧮

1

➖ Ayiruvchi

Qadam 1 dagi qo'shuvchini o'zgartir: + o'rniga − qo'y. Ikki sonni ayirsin.

🎯 Maqsad: a - b va Number()
2

✖️ Yosh × 365

Bitta katakcha yasa — unga yoshingni yoz. Tugma bosilganda yoshingni 365 ga ko'paytirsin va "Sen taxminan ... kun yashagansan! 🎂" desin.

🎯 Maqsad: yosh * 365 + .textContent
3

🧮 To'rt amalli kalkulyator

Qadam 2 dagi 4 amalli kalkulyatorni o'zing yoz. Katakchalarga value bilan boshlang'ich son ham qo'yib qo'y.

🎯 Maqsad: 4 tugma + if / else if
⭐

🧮 Qo'shimcha (qiyinroq!) — O'z kalkulyatoring

Qadam 3 dagi haqiqiy kalkulyatorni o'zing yasa: grid bilan tugmalarni tiz, eval() bilan hisobla. Tugmalarni o'z sevimli rangingga bo'ya! 🎨

🎯 Maqsad: grid + eval() + o'zgaruvchi
💡 Yordam kerakmi? Vazifa 2 (Yosh × 365) namunasi
<!DOCTYPE html> <html> <body style="text-align:center;font-family:sans-serif"> <h1>Necha kun yashagansan? 🎂</h1> <input id="yosh" type="number" placeholder="Yoshing"> <button onclick="hisobla()">Hisobla</button> <h2 id="natija"></h2> <script> function hisobla() { let yosh = Number(document.getElementById("yosh").value); let kunlar = yosh * 365; document.getElementById("natija").textContent = "Sen taxminan " + kunlar + " kun yashagansan! 🎂"; } </script> </body> </html>

Buni nusxalab, o'zgartirib boshqa vazifalarni ham shu tarzda bajar!
