O'zgaruvchi — bu son yoki matn saqlaydigan quticha. let ball = 0 deb yozsak, "ball" qutichasiga 0 solamiz. Keyin uni oshirish yoki kamaytirish mumkin! 👇

📄 To'liq kod — nusxalab brauzerda och
index.html
<h1 id="ball">0</h1>
<button onclick="kamaytir()">−</button>
<button onclick="oshir()">+</button>

<script>
  let ball = 0;                  // quticha: ichida 0
  function oshir() {
    ball = ball + 1;
    document.getElementById("ball").textContent = ball;
  }
  function kamaytir() {
    ball = ball - 1;
    document.getElementById("ball").textContent = ball;
  }
</script>
🔍 Kod qanday ishlaydi?
let ball = 0Ballni saqlaydigan quticha — hozircha ichida 0.
oshir()+ tugmasi buni chaqiradi: ball + 1.
kamaytir()− tugmasi esa ball - 1 qiladi.
.textContent = ballHar o'zgarishdan keyin ekrandagi son yangilanadi.

Ichida ko'p javob bor — JS tasodifan bittasini tanlaydi (random + if birga!)

📄 To'liq kod — juft/toq tekshirgich
index.html
<h1 id="natija">?</h1>
<button onclick="tekshir()">Tekshir</button>

<script>
  function tekshir() {
    let son = 8;                 // istalgan son
    if (son % 2 === 0) {         // AGAR qoldiq 0 bo'lsa
      document.getElementById("natija").textContent = "JUFT ✅";
    } else {                     // AKS HOLDA
      document.getElementById("natija").textContent = "TOQ 🔸";
    }
  }
</script>
🔍 Kod qanday ishlaydi?
son % 2Sonni 2 ga bo'lgandagi qoldiqni beradi (% = qoldiq belgisi).
=== 0Qoldiq 0 ga tengmi? Teng bo'lsa — son juft.
if ( ... )Qavs ichi rost bo'lsa — birinchi { } blok bajariladi.
elseAks holda (yolg'on bo'lsa) — ikkinchi blok bajariladi.
🔮 To'liq kod — sehrli shar (massiv + random)
index.html
<button onclick="sora()">Shardan so'ra 🔮</button>

<script>
  // massiv — ro'yxatdagi javoblar
  let javoblar = ["Ha! 😄", "Yo'q 🙅", "Ehtimol 🤔"];

  function sora() {
    // 0 dan javoblar soniga qadar tasodifiy o'rin
    let n = Math.floor(Math.random() * javoblar.length);
    alert(javoblar[n]);          // shu o'rindagi javobni ko'rsat
  }
</script>
🔍 Kod qanday ishlaydi?
["Ha", "Yo'q", ...]Massiv — bir nechta qiymatni saqlaydigan ro'yxat.
.lengthRo'yxatda nechta element borligini beradi (bu yerda 3).
random * lengthTasodifiy o'rin raqamini tanlaydi: 0, 1 yoki 2.
javoblar[n]Massivdagi n-o'rindagi javobni oladi (0 dan sanaladi).

📄 "Sonni top" o'yinining to'liq kodi — nusxalab brauzerda och
sonni-top.html
<!DOCTYPE html>
<html>
<body>
  <h1>Sonni top! (1 dan 20 gacha)</h1>
  <input id="taxmin" type="number">
  <button onclick="tekshir()">Tekshir</button>
  <p id="xabar"></p>

  <script>
    // 1) kompyuter 1-20 orasidan son yashiradi
    let maxfiy = Math.floor(Math.random() * 20) + 1;

    function tekshir() {
      // 2) foydalanuvchi yozgan sonni olamiz
      let taxmin = Number(document.getElementById("taxmin").value);
      let xabar = document.getElementById("xabar");

      // 3) uch holatni tekshiramiz (if / else if / else)
      if (taxmin === maxfiy) {
        xabar.textContent = "TOPDING! 🎉";
      } else if (taxmin < maxfiy) {
        xabar.textContent = "Kattaroq son tanla! ⬆️";
      } else {
        xabar.textContent = "Kichikroq son tanla! ⬇️";
      }
    }
  </script>
</body>
</html>
🔍 Kod qanday ishlaydi? (hamma narsa birga!)
Math.random … + 1Tasodif: kompyuter 1–20 orasidan bir sonni yashiradi (o'yin boshida bir marta).
let maxfiy = ...O'zgaruvchi: yashirilgan son shu qutichada saqlanadi.
.valueKirish: foydalanuvchi yozgan sonni Number() bilan songa aylantiramiz.
if / else if / elseShart: teng bo'lsa yutdi, kichik bo'lsa "kattaroq", katta bo'lsa "kichikroq" deydi.
.textContentKo'rsatish: natijani ekranga chiqaradi. Mana shu — HTML + JS jonli birga ishlashi! ⚡
